# Agricultural Data Analysis
-----------------------------

## Project Overview
--------------------
This project focuses on exploring and analyzing agricultural data using **Python, Pandas, NumPy, Matplotlib, and Seaborn**.

The analysis examines factors such as **rainfall, temperature, humidity, crop types, seasons, area, and price** to understand patterns and relationships within the dataset.

This project was created as a beginner-level **Exploratory Data Analysis (EDA)** project to practice data analysis and visualization techniques.

##  Objectives
------------------
* Explore and understand the agricultural dataset
* Check the structure and data types of the dataset
* Identify missing values
* Perform basic statistical analysis
* Filter and sort data using conditions
* Analyze crops, seasons, rainfall, temperature, and prices
* Create visualizations to understand patterns in the data
* Practice using Pandas, Matplotlib, and Seaborn

##  Dataset
-----------------
The dataset contains agricultural information with the following columns:

* Year
* Location
* Area
* Rainfall
* Temperature
* Soil type
* Irrigation
* yeilds
* Humidity
* Crops
* price
* Season
